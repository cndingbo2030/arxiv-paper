# Optional diagnostics

There are currently **no** `fig*.ipynb` notebooks in this directory.

Exploratory diagnostic plots are generated by Python scripts under
`experiments/scripts/`:

- `plot_dsm_training.py` → `paper/figures/dsm_training_curve.pdf`
- `make_fig_contraction_pilot.py` → `paper/figures/fig_contraction_pilot.pdf`
- `plot_sparse_pilot.py` → `paper/figures/fig_sparse_pilot.pdf`
- `make_fig_gaussian_discretization.py` → `paper/figures/fig_gaussian_discretization.pdf`

From the repository root, `make figures` first generates fresh fast-preset
arrays and then creates these plots. They are not included in the manuscript
and do not verify its theorems.
